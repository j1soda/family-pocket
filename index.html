⚠️ Firestore 데이터베이스의 [규칙(Rules)] 탭 설정을 확인해 주세요.

        
데이터베이스를 생성하셨다면, 부부 스마트폰에서 로그인 없이 바로 읽고 쓸 수 있도록 아래 규칙이 적용되어 있는지 확인해 주세요.

      

      

        

          
✅ 마지막 1단계: Firestore [규칙(Rules)] 탭 확인

          
파이어베이스 콘솔의 Firestore Database ➔ 상단 [규칙(Rules)] 탭에서 아래 코드를 붙여넣고 [게시(Publish)]를 누르면 즉시 초록불로 실시간 연동됩니다. (처음 만들 때 '테스트 모드'로 만드셨다면 이미 설정되어 있습니다!)

          
rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    match /{document=**} {
      allow read, write: if true;
    }
  }
}
